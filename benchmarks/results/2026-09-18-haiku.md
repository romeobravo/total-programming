# Benchmark results — 2026-09-18, Haiku 4.5

Clean Claude Code baseline vs. the eleven Total Programming principles, using
Ponytail's pinned agentic benchmark (`e3ba2aa`) on the FastAPI template (`cd83fc1`).
Both arms ran with `--safe-mode`, no user configuration, no plugins, no skills, and
file tools only. The treatment appended the canonical principles to the system
prompt; the baseline received nothing. 19 tasks × 2 arms × 4 repetitions = 152
sessions; 151 completed and 1 baseline session hit the 300-second timeout
(`tmpl-fe-wizard`, rep 1, excluded). Total reported list-price cost: $8.92.
Full raw evidence: `benchmarks/runs/full/` (gitignored; see `benchmarks/README.md`).

## Feature tier (12 tasks, per-task medians, n=4)

| arm | LOC | cost/run | time/run | tokens/run |
|---|---:|---:|---:|---:|
| baseline | 267.0 | $0.0907 | 75.4 s | 249,787 |
| total-programming | 151.5 | $0.0615 | 48.0 s | 184,700 |
| **delta** | **−43%** | **−32%** | **−36%** | **−26%** |

Per-task LOC (baseline → TP): colorpicker 424→136 (−68%), rating 215→78 (−64%),
dropzone 488→224 (−54%), datepicker 466→232 (−50%), wizard 957→610 (−36%),
command 421→284 (−33%); backend CRUD essentially unchanged (−9%…+7%) except
archive 74→101 (+36%). Same shape as Ponytail's published result: large cuts where
an over-build trap exists, a wash on irreducible code.

## Safety tier (7 tasks, n=4 per arm)

| arm | safe | correct | LOC | cost/run | time/run |
|---|---:|---:|---:|---:|---:|
| baseline | 28/28 | 28/28 | 12.4 | $0.0249 | 26.0 s |
| total-programming | 28/28 | 28/28 | 11.5 | $0.0179 | 16.3 s |

The principles did not trade safety or correctness for brevity on any adversarial
check (path traversal, SQL injection, HMAC tampering, rate-limit isolation, CSV
robustness, newline injection, cache correctness).

## Interpretation and limits

- Feature-tier "correct=1" only means code was delivered; feature completeness was
  not machine-verified. Spot checks show TP runs delivered single, working-looking
  components (e.g. an 82-line color picker on the native `<input type="color">`,
  a 70-line star rating) where baseline runs delivered multi-file component sets.
  Unlike Ponytail's ladder, TP never mandates the one-liner: the date picker still
  used Radix components rather than `<input type="date">`. The reduction is
  judgment-driven, not rule-driven.
- n=4 on one model (Haiku 4.5) with one seed order; treat percentages as
  directional, not precise. Dollar figures are CLI-reported list price, not
  subscription charges.
- Lower LOC is not itself the goal of the principles; this benchmark cannot
  measure maintainability or sustained pace. It shows the principles steer a
  coding agent toward materially smaller deliveries at lower cost and latency
  without dropping deterministic safety checks.
